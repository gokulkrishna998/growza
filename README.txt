GROWZA WEBSITE - STATIC HTML/CSS/JAVASCRIPT STARTER

FILES
- index.html: Home page
- about.html: About us
- courses.html: Course catalogue
- course-digital-marketing.html: Flagship course detail
- influencer-academy.html: Influencer and creator training
- blog.html: Blog / insights
- contact.html: Contact and enquiry form
- assets/style.css: Responsive styling, layout and parallax-ready visual effects
- assets/script.js: Mobile navigation, FAQ accordion, reveal animations and demo form behavior

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For a local server, open a terminal in this folder and run:
   python -m http.server 8000
4. Visit http://localhost:8000

IMPORTANT BEFORE PUBLISHING
- Replace sample contact email hello@growza.in with your verified business email.
- Replace sample/stock images with genuine photographs you own or have licensed.
- Connect the enquiry form to a real backend, CRM or form service. The included form is front-end demo behavior only and does not send submissions.
- Add actual trainer profiles, verified testimonials, learner outcomes, batch dates, fees and certification details. Do not publish unverified claims.
- Add privacy policy, terms, refund policy and cookie/privacy notices appropriate to your business.
- Review course descriptions, platform names and trademarks before launch.
- Google Fonts and Unsplash images are externally loaded and require internet access.
- This is a static front-end website. It does not include LMS login, student dashboard, payment processing or admin CMS.

DESIGN
Premium navy / white / electric-blue visual direction, responsive layouts, scroll reveal animations, sticky navigation, mobile menu, FAQ accordion, and a fixed-background parallax hero on supported devices. Reduced-motion preferences are respected.

INTERNATIONALIZATION & THEME UPDATE
- Dark/light mode toggle is included and preference is saved in browser localStorage.
- Language selector includes English, Arabic (RTL layout), Spanish, Dutch, French, German, Hindi and Malayalam.
- This starter currently translates shared navigation and CTA labels. Full page translation requires professionally reviewed translations for every page, course detail, form label, metadata and blog article.
- Arabic switches the document direction to RTL; review all layouts with native Arabic content before production.
- Language selector currently changes the interface language labels; it does not automatically translate every paragraph or course description.
